# Mini ATM Simulator

A simple console-based ATM simulator built using Core Java.

## Features
- Check Balance
- Deposit Money
- Withdraw Money
- Invalid amount handling
- Invalid choice handling
- Exit option

## Concepts Used
- Methods
- If-Else
- Switch-Case
- Do-While Loop
- Scanner
- Variables and Return Values
